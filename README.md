# WA Wrapper

A lightweight Android WebView wrapper for WhatsApp Web, with a clean navigation rail.

## Features

- Runs WhatsApp Web inside a flat WebView
- Hides the navigation rail for a cleaner, app-like experience
- No tracking, no ads, no cloud

## Install

Use the APK from [Releases](../../releases).

## Building

Open the project in Android Studio and run the `app` module, or build from the command line with Gradle.
